# 风格报告三层脱敏规范 (Desensitization Specification)

为确保风格能力报告可安全用于任意原创小说创作、防止专名泄漏与原型污染，执行"窄来源候选 + 三层脱敏 + 反向校验"。设计原则：**候选宁少勿滥**——候选来源限定为高置信说话人、《》术语与作者/作品身份三类，从源头排除通用词误收与截断伪名。

---

## 1. 三层脱敏规则

| 层次 | 脱敏对象 | 处理方式 | 校验标准 |
|---|---|---|---|
| **L1 作者身份** | 原作者姓名/笔名+作品标题 | 禁止扮演式绑定；默认公开头/Meta 仅登记 `WORK_xxxx`，真名仅私有模式出现 | 公开产物已知身份字符串泄漏为 0 |
| **L2 角色专名** | 对话标签 Top3 高频说话人 | 原型化替换为 2–4 字中性标签（如"角色甲"→"继承者"、"角色乙"→"摄政母后"） | 候选角色名在非引文正文泄漏次数为 0 |
| **L3 世界观专名** | 《》书名号实体（≤5 个） | 意象类型化提炼（如"某项保护法"→"行业信条"） | 不出现专名具体名词，只保留意象特征 |

## 2. 候选提取规则（窄口径）

`prepare` 阶段仅从三个可靠来源生成脱敏候选（通常 ≤10 项）：

1. **作者名 / 作品名**：恒定纳入，供反向校验看守；
2. **对话 Top3 高频说话人**：直接取自 dialogue_analyzer 的高置信声纹表（≥3 次出现且跨 ≥2 章；与实现同源，不在脱敏模块内重复实现说话人识别）；
3. **《》实体 Top5**：书名号内的世界观词条。

候选来源保持上述三类窄口径；通用停用词白名单（COMMON_WHITELIST ≤40 条）只用于拦截说话人识别中的动词/代词粘连残留。

## 3. 映射生成规则

LLM 在 JSON 数据块的 `desensitization_map` 中给出映射：

- **只映射候选池实际给出的条目**，替换标签用 2–4 字中性原型词；
- 禁止自行发明候选池之外的映射；
- 未覆盖的高分候选会以 `validation.warnings` 提示（不阻断）；正文或结构化字段出现原名则直接阻断。
- 映射键必须来自候选池；空值、原样映射、替换值再次包含原专名会阻断校验。

## 4. 反向校验与泄漏拦截

`finalize` 校验器执行 `validate_desensitization`：

- 先将映射应用到正文（带 `[chunk_id]` 的证据引文行豁免——引文本身允许包含原名）；
- 再检查非引文正文中候选专名与原作者名的出现次数；
- 任一泄漏：校验标记 `desensitization: failed` 并列出泄漏词清单，整份报告被拒绝；
- 脱敏映射表持久化为 `{base_name}_desensitization_map.json`（按报告名作用域，同目录多次 finalize 互不覆盖）供下游排查与复用；公开映射表只含中性标签，不含原键——原始键值映射仅保留在私有 sidecar；
- 替换标签建议 2–4 字中性原型词，超长标签记录 warning（兼容复合原型词示例）；
- `desensitize=False` 时全部脱敏（含 JSON 映射）跳过，`artifact_policy` 标记为 `raw`，产物仅限私有使用；
- `_rejected.md` 与 prepare 中间 JSON 含未脱敏原文与完整证据库，仅限私有保存与排查；
- 渲染后的公开产物会再做一次终检（meta 等渲染层字段也在看守范围内），发现身份泄漏即删除产物并拒绝。

## 5. 声纹清洗

高置信角色表经过归一化管线：迭代剥离窗口扫描粘连的动作动词（如"角色甲点"→角色甲、"角色乙回答道"→角色乙）、
阻断代词主语与指代词、合并别名并保留 `merged_aliases` 轨迹，
确保进入 Prompt 与报告的声纹数据均为干净的角色名。
