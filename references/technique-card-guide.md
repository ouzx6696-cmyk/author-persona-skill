# 技法调用卡编写指南 (Technique Card Guide)

技法调用卡是作家风格在微观场景中的可执行操作单元，供 `novel-writer` 在章纲设计与草稿写作时实时调用。

**技法的唯一定义**：句子/段落/标点/对话标签/描写配比/视角调度层面的行文机制。
它回答的是"作者怎么写"，而不是"故事写了什么"。

---

## 1. 合格卡示例

```json
{
  "id": "T01",
  "name": "对话尾逗号连写",
  "definition": "引语以逗号收尾，同段内接续一个动作分句再开启下一句引语，使对白与微动作形成连体段落，交锋节奏不断裂",
  "serves_purpose": "让多轮交锋的对白紧凑连贯，读者不因分段切换丢失攻防节奏",
  "trigger": "两人及以上连续交锋，需要在对话间隙插入微动作时",
  "steps": [
    "引语收尾用逗号而非句号",
    "中间插入的动作只留一个分句，不超过一次抬手/转身量级",
    "下一句引语紧随逗号之后开启，不另起段"
  ],
  "boundary": "独白、跨场景转场或三人以上混乱群口时禁用（归属会混乱）",
  "counterexample": "未发现明确反例",
  "evidence": [
    {
      "chunk_id": "c002",
      "quote": "“早一天晚一天有什么关系，”角色甲拍拍手，吩咐侍从上早餐，“坐下来慢慢说。”",
      "metric": "tag_frequencies",
      "note": "逗号收尾接动作分句再开启下一句引语，对白与微动作连体"
    },
    {
      "chunk_id": "c006",
      "quote": "“我满足了你的好奇心，大人，”她说，“现在可以杀死我了吗？”",
      "metric": "tag_frequencies",
      "note": "对白交锋中标签只承担归属，情绪由引语内容承载"
    }
  ],
  "transferability": "high",
  "confidence": "high"
}
```

## 2. 不合格卡对照

### 反例A：空泛词型
```json
{
  "name": "描写生动细腻",
  "definition": "写得非常生动吸引人",
  "trigger": "需要描写的时候",
  "steps": ["仔细观察", "写出细节"],
  "boundary": "",
  "evidence": []
}
```
错误：无辨识度、无机制、无场景信号、不可执行、边界与证据缺失。

### 反例B：情节梗概型（最易犯，内容闸门直接拒绝）
```json
{
  "name": "异能体系工程化解构",
  "definition": "将神秘力量视为可控能量，用现代科学原理定量分类并嵌入工业流程",
  "trigger": "主角接触新型异能者或攻关技术时",
  "steps": ["摒弃神秘学定义", "用对照实验测试边界", "接入生产流水线"]
}
```
错误：这是**故事设定与题材前提**，不含任何句式、段落、标点、标签层面的执行规则——照着它写不出任何一句具体的文字。判定特征：定义与步骤中出现"体系/工业/制度/战争"等题材域词，却找不到"句/段/标点/标签/比喻/视角"等机制词。

---

## 3. 编写铁律

1. **机制先行**：名称与定义必须落在行文层；校验器要求正文至少命中一个机制词表（句式/词汇词性/段落/标点/对话标签/描写/视角/节奏）。
2. **触发信号必须具象**：必须是叙事场景中的输入信号（如"两人连续交锋需要插微动作时"）；触发条件缺失会被内容闸门直接拒绝。
3. **失效边界三要素**：禁用场景 + 退化成因 + 规避动作（如"高潮对抗禁用——说教感打断情绪流；同章连续举例不超两处"）；边界空泛（如"慎用"/"无"）会被拒绝。
4. **步骤 3–5 步**：每步是可直接照做的操作。
5. **证据必须锚定**：quote 能在原文 chunk 中精确复核（规范化包含命中，6–80 字）；每张卡 ≥2 条；`metric` 必填并指向真实定量指标，全部证据缺 `metric` 将被拒绝；每条证据附一句 `note` 注解说明该句如何体现技法。
6. **serves_purpose 必填**：一句话写明本卡服务的阅读效果，回指第〇部分（作家契约）的读者体验条款。✅ "让多轮交锋的对白紧凑连贯"；❌ "提升文笔"（空泛词，不可判断）。缺失将被拒绝。
7. **反例必须显式声明**：不可留空，如无反例需显式写出"未发现明确反例"。
