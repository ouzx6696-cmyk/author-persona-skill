# 保真度闭环校验规范 (Fidelity Verification)

保真度闭环用于检验根据风格能力报告生成的虚拟作家提示词或泛化人格在全新试写场景下的文风复现程度。

**触发方式**：`finalize_analysis(..., trial_text=...)` 自动执行并写入报告附录；或独立调用 `run_fidelity_check(trial_text, reference_metrics, technique_cards)`。

---

## 1. 试写场景要求

试写 2–3 个全新场景（每个 ≥800 字）：
1. **日常互动/探索场景**：考察对话比例、句长呼吸与常态叙事节奏。
2. **高压冲突/打斗场景**：考察短句脉冲、动词切分与动作:心理比。
3. **关键抉择/危机场景**：考察思维层注意力顺序、信息控制与代价呈现。

**场景切分约定**：场景之间用单独一行 `---`（或 `===`）分隔；类型标注（日常/冲突/抉择）可写在场景正文开头，也可直接写进 `# 场景N：冲突` 这类标题分隔行——两种写法均生效，标注行会保留为该场景首行供类型覆盖校验读取。finalize 会强制校验场景数（2–3）与每场景字数（≥800），不满足直接使 fidelity 失败；标注类型时三类必须齐全，未标注则记入提示不阻断。分场景摘要指标写入报告附录。

---

## 2. 定量指标偏差容差表（默认阈值）

| 核心指标 | 容差 | 说明 |
|---|---|---|
| 平均句长 (avg_sent_len) | ±15% | 控制叙事基本呼吸节奏 |
| 对话字符占比 (dialogue_ratio) | ±10 个百分点 | 保证互动与叙述平衡 |
| 短句率 (short_sent_ratio) | ±10 个百分点 | 控制动势推进密度 |
| 比喻密度 (metaphor_density) | ±30% | 保证修辞点染一致性 |

可通过 `run_fidelity_check(..., tolerances={...})` 覆盖默认值。

### 2.1 作者自然波动区间（动态容差，优先于固定阈值）

固定阈值是兜底；当 prepare 产出的 `era_window_metrics`（每时期一个窗口）≥4 个时，`derive_dynamic_tolerances` 会按**中位数 ± 3·MAD** 为四项核心指标各推导一条作者自然波动区间：

- 试写值落在区间内 → 该指标直接达标，`deviations_table[].basis` 记为 `author_band`，阈值列追加「（作者自然波动区间内）」；
- 试写值落在区间外 → 回落到固定容差判定，`basis` 记为 `fixed_tolerance`；
- 窗口不足 4 个（短语料/时期过少）→ 不生成区间，全部按固定容差判定。

这张表由规格表统一生成，四项指标一视同仁；`finalize_analysis(..., trial_text=...)` 会自动传入 `era_window_metrics`，独立调用 `run_fidelity_check` 时需自行传 `window_metrics=`。

## 3. 技法卡逐项验收

### 可自动检测的技法范围（8 类 profile）

卡片定义/步骤中出现对应关键词时，映射到可执行的表面行文标记进行自动判定：

| profile | 判定关键词 | 检测标记 |
|---|---|---|
| metaphor（比喻点染） | 比喻 / 点染 / 喻体 | 宛若、仿佛、如同、犹如、像、如 |
| action（动作连缀） | 动作 / 推拉 / 切分 / 动词 | 拔、斩、冲、退、出拳、踏、抓、挥 |
| question（设问线索） | 设问 / 线索 / 疑问 / 反问 | 难道、为何、究竟、？、? |
| ellipsis（省略号悬置） | 省略号 / 悬置 | ……、... |
| dash（破折号揭底） | 破折号 / 揭底 | ——、-- |
| dialogue_tag（对话标签） | 对话标签 / 标签 / 说话人 / 对白 / 台词 / 声纹 / 口癖 | 说道、问道、答道、笑道、说、道、问、引号 |
| perspective（视角人称） | 视角 / 人称 / 镜头 / 景别 / 限知 / 全知 | 他、她、我、你 |
| rhythm（段落节奏） | 节奏 / 段落 / 换行 / 收束 / 转场 / 留白 / 悬念 / 节拍 | 结构判定：极短段数量与段落总数 |

**范围边界（设计如此，非缺陷）**：上述 8 类以外的技法卡无法从卡片文本推导出可执行的表面检测特征，一律判定 `not_applicable` 并记录原因——**不会因无法检测而假判通过**。这是保守降级：`fidelity.status` 只由 4 项定量指标 + 8 类可检测技法决定；其余技法卡不参与通过/失败判定。

其中 `dialogue_tag` 为引用感知检测：给出 `reference_metrics` 时，实测主力对话标签若在试写中缺失即判 `uncovered`；`rhythm` 为结构检测（极短段或 ≥3 段即视为具备段落呼吸）。

核对试写正文中技法卡表现：
- **体现 (covered)**：场景符合触发条件时正确调用，未触发失效边界。
- **走样 (deformed)**：调用时破坏了边界条件或步骤缺失。
- **未覆盖 (uncovered)**：相关场景出现但未激活技法。
- **不适用 (not_applicable)**：卡片定义无法推导出可靠的可执行检测特征；记录原因，不因未知而假判通过。

`validation.status` 只表示报告结构、Schema、证据、脱敏和数值审计；`fidelity.status` 单独表示试写闭环。顶层 `status` 只有在两者都通过（或未启用 fidelity）时才为 `passed`。任何 `uncovered`、`deformed` 或 fidelity 内部异常都会使 fidelity 失败，并写入附录逐卡说明。

全部定量指标与适用技法核对达标后输出 `fidelity: passed`；finalize 会把偏差对比表与逐卡判定写入报告附录。
