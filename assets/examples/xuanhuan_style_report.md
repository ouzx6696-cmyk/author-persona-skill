## 第〇部分：作家定义与读者契约（作家契约层）

### 〇.1 定位（Positioning）
高压快节奏、异象升级流玄幻，面向快节奏连载平台的中长篇读者。

### 〇.2 写作目的与读者契约（Purpose & Reader Contract）
读者每章至少获得一次危机推进与一次异象奇观；打斗必有可见物理结果，升级必有不可逆代价，章末必留翻页钩子。

### 〇.3 风格标记综合（Style Marks Synthesis）
高频短句脉冲、异象比喻点染、强动作驱动、悬念留白结尾四者交替：短句切分动作节拍，单句比喻完成奇观映射，动作结果句收束段落，破折号与省略号留白收尾留出翻页钩子，整体形成「压迫—爆发—定格—悬停」的阅读律动。

### 〇.4 敌人条款（Enemy Clauses）
- 严禁解释性副词与内心权衡拖慢动作节拍
- 严禁连续三段以上无场景切换或动作落点
- 严禁全知旁白一次性倒出设定真相

## 第一部分：定量风格分析报告（定量层）

### 1.1 文本基础概况
样本覆盖总字符 112,400 字，分段 1,840 段，有效句子 5,210 句。平台求票与水印噪音过滤占比 0.82%。整体题材属于高压快节奏、异象升级流玄幻，行文强调视觉冲击与危机迫近感。

### 1.2 句式结构特征
平均句长 21.5 字，中位句长 18.0 字。短句率（≤10字）高达 36.2%，长句率（≥50字）仅 4.1%。句长分档属于“中短 (清晰利落/动势平稳)”，在打斗与异象降临时通过极短单句形成密集的动势脉冲。

### 1.3 段落与节奏结构
平均段长 61.0 字，极短段率（≤8字）为 14.5%，场景切换密度 2.4/千字。段落换行果断，大量采用单句成段强化悬念与画面定格。

### 1.4 对话与叙事比例
对话字符占比 34.8%，对话标签频次以“道（54%）”、“问（18%）”、“冷笑（12%）”为主，道:说比为 4.8:1。角色对话高度任务驱动，几乎无闲聊，对白常伴随身体动作或杀机试探。

### 1.5 标点符号使用
每千字逗号 48.2，句号 32.1，破折号 1.8，省略号 2.4。叹号与问号合计密度 6.5/千字。逗句比 1.50，破折号与省略号的高频使用表明作者偏好情绪留白与瞬间转折。

### 1.6 修辞手法
比喻密度达 3.8/千字，以高饱和色彩（幽蓝、赤金、漆黑）与宏大天体/神话意象为映射物；反问句密度 1.2/千字；排比句密度 0.8/千字。修辞引擎以“瞬间点染”为主，极少铺陈长篇静态描摹。

### 1.7 视角与叙事
第三人称代词计数 4,180 次 vs 第一人称 402 次（占比 91.2%），以第三人称紧跟主角行动的限知视角为主。镜头距离通常为“特写动作 → 广角异象 → 中景对峙”，推拉节奏极快。

### 1.8 描写密度
动作动词频次 42.1/千字，心理动词 11.2/千字，环境词 18.4/千字。动作:心理比为 3.76:1，属于典型的“强动作/事件驱动模式”，人物性格与局势完全通过行动外化。

### 1.9 角色对话风格
- **主角原型（冷静探路型）**：对白简短，多用短句设问与冷峻判断，平均句长 14.2 字。
- **异化伙伴原型（碎嘴通灵型）**：口吻谐谑，善用反问与惊呼，形成紧张氛围下的轻度反差。

### 1.10 世界观与词汇
高频意象群集中于“矿物晶体”、“雷霆异象”、“古老器物”、“星空深渊”等类型化意象。不依赖具体原著名词，而依赖高饱和色彩与异化质感构建奇观。

### 1.11 风格标记
1. 高频短句脉冲（短句率 36.2%，动词密集切分）
2. 异象比喻点染（每千字比喻 3.8 次，单句完成意象映射）
3. 强动作驱动叙事（动作:心理比 3.76）
4. 悬念留白结尾（破折与省略号高频）

## 第二部分：核心写作技法提取（技法调用卡层）

### T01：异象比喻点染
- **定义**：在危机或未知场景中，用具象矿物/天体意象点化寻常物理现象，替代静态环境交代。
- **本卡服务的阅读效果**：让读者在危机瞬间获得具象化的异象奇观体验。
- **触发条件**：主角目击异象、遭遇突发超自然危机或进入未知地界时。
- **写法要点**：
  1. 定位句中已出现的寻常物理动作或物体（如光芒、声音、山风）。
  2. 用“如/宛若/如同一柄”等比喻词映射到具有压迫感的高饱和意象。
  3. 单句内完成比喻并立即接动作切分，不延展成单独描写段落。
- **失效边界**：高速攻防或角色密集对白交互时禁用；同一场景连续比喻超过2次会产生审美疲劳。
- **反例/禁忌**：打斗高速段若使用长定语比喻会导致节奏停滞。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c002] “已校验证据（内容已隐藏）” (metaphor_density) — 注解：喻体取自“九幽裂隙/冷火”这类高饱和幽暗意象，单句内完成映射后立刻接“冻结虚空”的物理结果，未延展为独立描写段。
  - [c011] “已校验证据（内容已隐藏）” (short_sent_ratio_pct) — 注解：以“大日横空”比喻拳印，比喻与“山体崩开”的结果压缩在同一句内，避免长定语拖慢攻防节奏。

### T02：动作连缀推拉
- **定义**：用连续单音节/双音节及物动词切分肢体交互，以极短停顿完成攻防回合。
- **本卡服务的阅读效果**：让冲突回合保持高速推进的打击感。
- **触发条件**：近身冲突爆发、突发险情规避时。
- **写法要点**：
  1. 剔除动作间的修饰副词与内心权衡。
  2. 每句只承载一个动作，以逗号或短句快速推进。
  3. 结尾句直接落在一个可见的物理结果上（如地面凹陷、兵刃震颤）。
- **失效边界**：文戏谈判或复杂阵法推演时禁用。
- **反例/禁忌**：动作过程中插入超过10字的思想活动会破坏打击感。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c005] “已校验证据（内容已隐藏）” (short_sent_ratio_pct) — 注解：三个双音节及物动词以逗号连缀，每句只承载一个动作，无修饰副词与内心权衡。
  - [c009] “已校验证据（内容已隐藏）” (action_mental_ratio) — 注解：连续单音节动词切分攻防回合，末句直接落在“撞断古木”这一可见物理结果上。

### T03：设问线索投喂
- **定义**：主角在对白或独白中提出阶段性疑问，同步向读者投喂关键世界观线索与危机预警。
- **本卡服务的阅读效果**：把未知转化为可追读的线索钩子，维持探索张力。
- **触发条件**：探索新区域、发现反常线索或战后复盘时。
- **写法要点**：
  1. 由眼前可见的具体异状发起疑问。
  2. 结合过往经验做出两种对立推测。
  3. 暂不给出确切答案，以未知驱动下一步行动。
- **失效边界**：决战高潮或生死关头禁用长设问。
- **反例/禁忌**：自问自答直接公布真相会消除悬念。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c003] “已校验证据（内容已隐藏）” (rhetorical_question_density) — 注解：由眼前“纹路”这一具体异状发起疑问，不下结论，以未知驱动下一步探索行动。
  - [c007] “已校验证据（内容已隐藏）” (rhetorical_question_density) — 注解：设问后不作回答，直接接“握紧刀柄”的动作，把悬念转译为可执行的行动压力。

## 第三部分：作家创作思维与宏观心智（思维层）

### 3.1 注意力顺序 (Attention Order)
进入场景时，注意力严格遵循“局部动态异象 → 物理实体威胁 → 自身状态与兵器 → 宏观环境与他人反应”的顺序展开，始终将威胁信号置于第一位。

### 3.2 信息控制 (Info Control)
关键秘密实行阶梯式延迟揭示。遇到世界观真相时，先给断裂碎片的表象线索，促使主角与读者共同产生推测，绝不通过全知旁白一次性倒出设定。

### 3.3 冲突升级 (Conflict Escalation)
压力阶梯式层层加码：初现异变 → 现场目击 → 利益/生存卷入 → 强敌压制 → 绝境破局。每次化解旧冲突时，必然在尾部引出更高维度的危机。

### 3.4 代价管理 (Cost Management)
力量成长与胜利必然伴随不可逆代价（器物损毁、伤势反噬、引来更强注视），坚决杜绝无风险的零代价爽感。

### 3.5 收束方式 (Closure Pattern)
单章结尾极少做情绪沉淀或抒情总结，均以“未定态的画面”或“新突发信号的出现”作为钩子收束，保持强烈翻页欲望。

### 3.6 长线布局 (Long Arc)
前文微小伏笔（不起眼的残破信物、一句随口传闻）跨越数十乃至百章后在主线转折点爆发回收，形成卷级不可逆剧变。

### 3.7 题材适配边界 (Adaptation Boundary)
极度适合：高武玄幻、异兽末日、危机探险、快节奏升级流小说。
不适合：慢热日常种田、治愈系群像、注重细腻心理独白的纯文学。
