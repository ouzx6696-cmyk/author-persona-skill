明快诙谐、烟火气浓郁的历史种田与市井争斗流，面向偏好人情世故细节的连载读者。

## 第一部分：定量风格分析报告（定量层）

### 1.1 文本基础概况
样本覆盖总字符 86,500 字，分段 1,120 段，有效句子 3,450 句。噪音过滤占比 0.45%。题材属于明快诙谐、烟火气浓郁的历史种田与市井争斗流，注重器物细节与人情世故描写。

### 1.2 句式结构特征
平均句长 24.2 字，中位句长 21.0 字。短句率（≤10字）28.4%，长句率（≥50字）6.8%。句长分档属于“中短 (清晰利落/动势平稳)”，句子兼具口语流动性与白描质感。

### 1.3 段落与节奏结构
平均段长 77.2 字，极短段率 9.8%，场景切换密度 1.6/千字。段落多为“情境概述 + 对话互动 + 人情细节”的三拍子结构，节奏舒缓而有层次。

### 1.4 对话与叙事比例
对话字符占比 46.2%，对话标签丰富，涵盖“笑道（32%）”、“叹道（18%）”、“骂道（14%）”、“打趣道（8%）”，道:说比为 3.2:1。对白具有强烈的口语交锋与世俗机敏感。

### 1.5 标点符号使用
每千字逗号 52.4，句号 28.6，冒号 4.5，引号密集。逗句比 1.83，反映出句式常通过逗号做小步连缀与从容铺陈。

### 1.6 修辞手法
比喻密度 2.1/千字，偏好市井食物、民俗俗谚与日常器物类比；反问与设问密度 1.8/千字；极少使用宏大神话排比，以世俗白描为主。

### 1.7 视角与叙事
第三人称代词计数 1,690 次 vs 第一人称 219 次（占比 88.5%），叙事者带有轻微调侃与市井通达的态度，与角色保持适度近景距离。

### 1.8 描写密度
动作动词 30.5/千字，心理动词 14.2/千字，器物与食物环境词 22.8/千字。动作:心理比 2.15:1，心理活动常通过微表情与市俗计算外化。

### 1.9 角色对话风格
- **主角原型（精明诙谐型）**：擅长插科打诨、退让中设局，平均句长 18.5 字。
- **长辈同僚原型（保守威严型）**：口吻持重，多用教训与反诘，形成戏剧冲突。

### 1.10 世界观与词汇
高频意象集中于“炊烟、铜钱、茶肆、青石板、绸缎、家常饭菜”等市井民俗意象，烟火气息扑面而来。

### 1.11 风格标记

## 第二部分：核心写作技法提取（技法调用卡层）

### T01：市井俗谚点题
- **定义**：在人物决策或评判局势时，借用市俗谚语或生活经验完成微观定性，增强烟火质感。
- **本卡服务的阅读效果**：用烟火质感的俗谚定性让世故判断显得可信可亲。
- **触发条件**：主角处理人情世故纠纷、市井商业谈判或复盘得失时。
- **写法要点**：
  1. 捕捉当下人情矛盾的核心利益点。
  2. 引入一句家常俗话或市井行规作比。
  3. 借俗语顺势推导出符合常理的应对方案。
- **失效边界**：朝堂大政辩论或生死搏杀关头禁用。
- **反例/禁忌**：生搬硬套文绉绉的书面典故会破坏市井语感。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c002] “已校验证据（内容已隐藏）” (metaphor_density) — 注解：借“当铺”这句市井行规完成对局势的微观定性，不落抽象评判，烟火质感由俗谚本身承载。
  - [c008] “已校验证据（内容已隐藏）” (short_sent_ratio_pct) — 注解：两句对仗俗谚后立刻接“端起茶碗”的动作，把判断落在人物举止上，而非旁白议论。

### T02：器物动作衬托心机
- **定义**：用整理衣袍、摆弄茶具、数铜钱等具象手部动作，替代直接的心理独白，展现人物内心盘算。
- **本卡服务的阅读效果**：让内心盘算可见而不可说，读者获得看破不说破的会心。
- **触发条件**：谈判对峙、各怀心思的席间寒暄时。
- **写法要点**：
  1. 选取一个身边可触及的细小器物。
  2. 描写动作的停顿、轻重或节奏变化。
  3. 借动作的结束引出下一句试探性对白。
- **失效边界**：开阔战场或单人赶路场景不适用。
- **反例/禁忌**：动作描写过于冗长而脱离对白节奏。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c004] “已校验证据（内容已隐藏）” (action_mental_ratio) — 注解：以拨算盘这一可触器物的手部动作替代心理独白，末句“余光”点出未言明的盘算。
  - [c010] “已校验证据（内容已隐藏）” (short_sent_ratio_pct) — 注解：借刮茶盖的节奏停顿承载权衡，动作结束即引出话头转折，全程不写内心活动。

### T03：标签动词情绪外化
- **定义**：用“笑道/叹道/骂道/打趣道”等动作性对话标签动词直接承载说话情绪与人物关系，替代“愤怒地说”式副词修饰。
- **本卡服务的阅读效果**：让对白情绪直接外化，交锋场面不靠副词也立体可感。
- **触发条件**：市井对白交锋、席间寒暄、讨价还价等多人对话场景。
- **写法要点**：
  1. 先判断本句说话人的情绪基调与双方身份关系。
  2. 选用一个兼具动作与情绪的标签动词（如笑道、骂道、打趣道）挂在引语后。
  3. 情绪浓度高时让标签动词独立收尾小句，不追加语气副词。
- **失效边界**：悲恸、隐忍等低强度内敛情绪场景不适用——本书标签动词库以高外放市井情绪为主。
- **反例/禁忌**：连续多句复用同一标签动词会显露机械感；“说道”类中性标签不承载情绪，不构成本技法。
- **迁移性 / 置信度**：HIGH / HIGH
- **证据支撑**：
  - [c006] “已校验证据（内容已隐藏）” (tag_frequencies) — 注解：标签动词“笑道”直接外化掌柜的圆滑客套，情绪由标签本身承载，无需副词补充。
  - [c012] “已校验证据（内容已隐藏）” (dao_shuo_ratio) — 注解：高冲突对白以“骂道”收尾定性，配合本书 3.2:1 的高标签密度，情绪外放成为对白基调。

## 第三部分：作家创作思维与宏观心智（思维层）

### 3.1 注意力顺序 (Attention Order)
进场景先看人际座次与衣着器物细节，再听言语交锋，最后体察暗流涌动的利益纠葛。

### 3.2 信息控制 (Info Control)
通过市井流言、账册账目、闲聊碎语渐进式渗透关键线索，让主角在日常互动中逐步拼凑真相。

### 3.3 冲突升级 (Conflict Escalation)
微小的人情摩擦或利益分歧 → 规则与人脉博弈 → 局势升级为家族/门阀对峙，层层由暗转明。

### 3.4 代价管理 (Cost Management)
每次获利都伴随着人情债的欠下或潜在政敌的戒备，平衡世故是持续的主题。

### 3.5 收束方式 (Closure Pattern)
章末常以一句耐人寻味的市井对白或对明日生计的着落作为收尾，余味悠长。

### 3.6 长线布局 (Long Arc)
看似不起眼的市井小人物或小发明，在后续大势变动中成为撬动局面的关键支点。

### 3.7 题材适配边界 (Adaptation Boundary)
适合：历史风俗、古代种田、市井生活、经商争霸类小说。
不适合：快节奏高武修真、纯硬科幻。
